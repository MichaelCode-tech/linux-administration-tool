# Linux Administration Tool

A comprehensive system administration tool designed for Linux beginners and experienced users alike. Manage your system efficiently with an intuitive interface that works across all Linux distributions.

## Features

- **System Information** - View detailed system and hardware information
- **System Cleaner** - Remove temporary files and free up disk space
- **User/Group Management** - Create, modify, and delete users and groups
- **Archiving** - Compress and extract files with ease
- **Search TUI** - Interactive terminal UI for searching files and content
- **Systemd Management** - Control and manage system services
- **Links** - Manage symbolic and hard links
- **Swap Management** - Configure and monitor system swap

## Requirements

- Linux operating system (any distribution)
- Bash shell
- Superuser (sudo) privileges for certain operations

## Installation

```bash
git clone https://github.com/MichaelCode-tech/linux-administration-tool.git
cd linux-administration-tool
chmod +x linux-administration-tool.sh
```

## Usage

```bash
./linux-administration-tool.sh
```

Follow the on-screen menu to access different features and tools.

## Supported Distributions

This tool works across all major Linux distributions including:
- Ubuntu/Debian
- Fedora/RHEL
- Arch Linux
- OpenSUSE
- And others
